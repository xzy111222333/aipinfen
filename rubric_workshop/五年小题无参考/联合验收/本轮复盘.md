# 从低分追到具体规则

本轮在原有 JSON 制标、引文核对与 Python 汇总入口上修改。冻结后才发送答卷给阅卷模型。针对两道争议题做了开发性回测；这些题此前多次参与调试，不充当独立验证集。各次分数均是系统试评分。

## 三次对照

1. 修订通用提示，要求同一意思只给一次，独立操作分别给部分分。发布词制标中转失败后沿用上一轮冻结表作为对照，在表中记录了 base_file。葡萄园表新增加农文旅，移除绿色认证，但仍把自然条件、品种、光合、水土等局部细节过度拆分。白鹭原卷4分，删储碳反升到4.5分，这版明显失败。
2. 在相同项目和权重下只缩短最低充分条件，四题均用原卷回放。葡萄园白鹭5，发布词白鹭9、另一篇14.5，城市用光两份6.5与4.25，汇报提纲7.25。葡萄园两份储碳同义表达等分；删储碳分数虽降，小气候和技艺传承也各少0.5。发布词错误地继续把多步流程捆成整项。压短判据不等于得到正确的最低条件。
3. 对葡萄园和发布词另行人工审定两份对照表。已看过答卷，仅用于检验低分成因。葡萄园按实践、生产防护、小气候、绿色与储碳、生态关系与持续利用给分，同一关系允许上位概括或恰当实例。发布词仍用15+5；把报名入口、培训、观察、提交、校验分别核查，公文结构用语独立判。两题不以命中白鹭用词为条件。人工表和打分引文均保留在“人工审定边界对照”。这一步检验能否制定一把可解释的尺，不能证明零机构自动制标已经达到同样水平。

## 保留和拒绝

保留既有三类题、两类小题计分预算、证据核对与算分。保留固定的联合回放和原则文档。暂不采纳纯缩句生成方案为默认；聚焦同一项目是否买了若干不相干的信息、答对其中一部分是否真的有相应得分台阶。用分数方向与逐项差异同时验收。若删去一个事实，答卷中仍逐字保留的其他证据突然失分，回放程序会列出相关项目供复核。

重放实验可用 python -m rubric_workshop.joint_replay --output <本轮目录>。比较相同预算的简化版，可另设新目录并加 --minimum-from <冻结表目录>。外部模型的独立调用会波动，文件是本次实测记录；重复评估不可替换旧文件。后续候选改动须同时看两道重点题与两道保护题，并拿未参与本轮调试的题再次验收。
