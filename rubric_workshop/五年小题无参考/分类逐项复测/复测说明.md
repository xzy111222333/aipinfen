# 分类制标回测

制标输入为题干、指定材料、预先划定的题型与预算；冻结后才读取答卷。重放用卷见同目录 JSON，base 指向实际使用的细则。第一轮分类与同期通用版直接从材料建表。第二轮仅更换第一类的方面分档方式，公文保留交付任务分区。最后固定同一张表，比较只报命中项与逐项核查两种评分。年度和题位均为开发样本，观察分数没有官方单题标签。

葡萄园首轮通用、分类各给白鹭5分；方面分档后，只报命中项给10分，逐项核查给6分。同义储碳答句在后者均得2分，泛写保护土壤得0分。分别从完整答卷删掉碳库、文旅，各由6降至5。漏斗架分档仍把光合、防风、抗冲刷等多个细节合成一个基础条件，却能在未认基础时给生产与生态防护关系分。方面分档没有通过整卷的一致性检验。

这轮支持按题干任务生成不同细则并沿用统一证据校验。分类方式和两档等额均作为实验变量。分差要核对对应语义，不能以白鹭达到目标分或两篇局部答句同分作为整题验收。
